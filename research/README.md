# Private project research

This owner's repository tracks synthetic engineering research. Keep reusable checks in tests/ or scripts/verify/; retain notes, prototypes and evidence here.

- notes/: decisions, audits, section maps and follow-up proposals.
- prototypes/: disposable experiments using fictional inputs.
- evidence/: sanitized verification records tied to a revision.

Never commit real financial records, notification samples from real accounts, screenshots containing real balances, credentials or personal context. PROJECT_STATE.md and JOURNAL.md remain local and excluded from Git. The original state backup is kept outside this repository with private permissions.
